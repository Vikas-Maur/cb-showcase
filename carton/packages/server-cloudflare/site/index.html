Cardboard, on Windows

Cardboard only ships for Apple Silicon Macs. This is its Mac app turned into a Windows app, with Windows versions of every tool it bundles. It’s one download with nothing to install: run it, choose a folder to unpack into, then open Cardboard.exe and sign in with your Cardboard account.

It also has Carton, version history for video. Every change is kept and says who made it: you, a teammate, the Director or Claude Code. Try ideas in separate cuts, fold the parts you like back in, go back to any version, and share a project to edit it live with someone else.

And it fixes bugs that are still in Cardboard’s own code, each one marked in red in the changelog. It’s an independent project, not made by or affiliated with the Cardboard team.
